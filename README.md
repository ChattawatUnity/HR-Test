# แบบทดสอบผู้สมัครงาน (HR-Test)

เว็บแบบทดสอบผู้สมัครงาน 4 ส่วน ทำเรียงตามลำดับ ย้อนกลับไม่ได้ จับเวลาแต่ละส่วน
บันทึกความพยายามคัดลอก-วางและการสลับหน้าจอ แล้วส่งผลเข้า Google Sheets

| Part | เนื้อหา | เวลา (ค่าเริ่มต้น) | การให้คะแนน |
|---|---|---|---|
| 1 | พิมพ์ภาษาไทยตามต้นฉบับ | 3 นาที | WPM (5 ตัวอักษร = 1 คำ), ความถูกต้อง (1 − ระยะ Levenshtein / ความยาวต้นฉบับ) |
| 2 | พิมพ์อีเมลอังกฤษใน UI จำลอง Gmail | 10 นาที | To / Cc / Subject / Body ถูกต้องอย่างละ 1 คะแนน (เต็ม 4) + % ความคล้ายของ body |
| 3 | ตรวจแก้ Bill of Lading ให้ตรงต้นฉบับ | 10 นาที | จำนวนช่องผิดที่แก้ถูก / จำนวนช่องผิดทั้งหมด และนับช่องถูกที่ถูกแก้จนผิด |
| 4 | คำศัพท์ shipping 12 ข้อ ปรนัย | 5 นาที | ข้อถูก / 12 |

เป็น static site ล้วน (HTML/CSS/JS) ไม่ต้อง build เปิดไฟล์ `index.html` ผ่าน web server ใดก็ได้

## โครงสร้าง

```
index.html            หน้าเดียว
css/style.css         สไตล์ทั้งหมด
js/config.js          << ค่าที่ HR แก้ได้ทั้งหมดอยู่ที่นี่ >>
js/scoring.js         ฟังก์ชันคำนวณคะแนน
js/part1.js..part4.js หน้าจอแต่ละ part
js/app.js             ลำดับขั้นตอน, จับเวลา, กันโกง, ส่งผล
apps-script/Code.gs   สคริปต์ฝั่ง Google Sheets
```

## การแก้ไขข้อสอบ (`js/config.js`)

- `TIME_LIMITS` เวลาแต่ละ part (วินาที)
- `PART1_TEXT` ข้อความไทยที่ให้พิมพ์
- `PART2` อีเมลปลายทาง, CC, subject, body ที่ต้องพิมพ์
- `BL_ORIGINAL` ข้อมูล B/L ต้นฉบับ (แกะจาก PDF หน้า 1)
- `BL_WRONG` ช่องที่ทำให้ผิด ใส่เฉพาะ key ที่ต้องการให้ผิดพร้อมค่าที่ผิด ช่องที่ไม่ระบุจะเท่ากับต้นฉบับ
- `PART4` ข้อสอบปรนัย `answer` = index ของตัวเลือกที่ถูก (เริ่มจาก 0)
- `SHEETS_ENDPOINT` URL ของ Apps Script (ดูด้านล่าง)

## ตั้งค่า Google Sheets

1. สร้าง Google Sheet ใหม่ → เมนู **Extensions → Apps Script**
2. ลบโค้ดเดิม วางเนื้อหาจาก `apps-script/Code.gs` แล้วบันทึก
3. **Deploy → New deployment** → ประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
4. กด Deploy, อนุญาตสิทธิ์ แล้วคัดลอก **Web app URL**
5. วาง URL ลงใน `js/config.js` ที่ `SHEETS_ENDPOINT`

ถ้าสร้างสคริปต์จาก script.google.com โดยตรง (ไม่ได้สร้างจากในชีต) สคริปต์จะสร้างชีตชื่อ **HR-Test Results**
ให้เองใน Google Drive ตอนมีผลแรกเข้ามา หรือใส่ ID ของชีตที่ต้องการในตัวแปร `SPREADSHEET_ID` ใน Code.gs ก็ได้
เปิด URL ที่ลงท้าย `/exec` ในเบราว์เซอร์จะบอกว่าผลถูกบันทึกลงชีตไหน

**หลังแก้ Code.gs ทุกครั้ง** ต้อง Deploy → Manage deployments → ✎ → Version: **New version** → Deploy ไม่งั้น URL เดิมจะยังรันโค้ดเก่า

ผลสอบจะถูกเพิ่มเป็นแถวในชีต `Results` (สร้าง header ให้อัตโนมัติ) คอลัมน์ `raw_json` เก็บคำตอบดิบทุกส่วน
รวมถึงข้อความที่ผู้สมัครพิมพ์และ log การฝ่าฝืน

ถ้าไม่ได้ตั้ง `SHEETS_ENDPOINT` หรือส่งไม่สำเร็จ หน้าสรุปจะมีปุ่มดาวน์โหลดไฟล์ผล (JSON) ให้ผู้สมัครส่งให้เจ้าหน้าที่แทน

## เปิดใช้งาน

- ทดสอบในเครื่อง: `python3 -m http.server 8080` แล้วเปิด http://localhost:8080
- Deploy จริง: เปิด GitHub Pages ของ repo นี้ (Settings → Pages → branch main, root)

## หมายเหตุการกันโกง

- บล็อกและบันทึก paste / copy / cut / drop / คลิกขวา ระหว่างทำแต่ละ part
- บันทึกทุกครั้งที่หน้าเว็บถูกซ่อน (สลับแท็บ) หรือหน้าต่างเสียโฟกัส
- เวลาใช้ deadline จริง รีเฟรชหน้าแล้วเวลาไม่รีเซ็ต และย้อนกลับ part ก่อนหน้าไม่ได้
